# Phase 5.3 Audit UX Improvements Plan

## Goal

Make the audit page more useful for operators without adding major backend complexity.

## Scope

- improve audit event readability
- add simple event filtering
- add simple actor filtering
- preserve Admin-only access

## Initial Success Criteria

- Admin can filter audit entries by event type
- Admin can filter audit entries by actor text
- audit page remains readable with existing data
- tests and build still pass
