# Phase 4.4 Non-Production Delivery Plan

## Goal

Refine the application handoff so the MVP can be run more reliably outside pure developer workflow.

## Scope

- define a clearer production-like local start path
- document environment and startup expectations
- provide an optional lightweight process manager path
- improve rollout checklist for non-production usage

## Initial Success Criteria

- app can be built and started with a documented sequence
- operator-facing non-production notes are clearer
- handoff docs reflect the current MVP shape
