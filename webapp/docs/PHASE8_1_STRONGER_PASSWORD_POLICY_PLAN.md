# Phase 8.1 Stronger Password Policy Plan

## Goal

Strengthen password quality requirements and make reset submissions safer.

## Scope

- define stronger password validation rules
- apply the same rules to password reset completion
- keep user-facing errors clear and safe
- avoid breaking current auth flows unexpectedly

## Initial Success Criteria

- weak passwords are rejected consistently
- strong passwords continue to work
- reset flow uses the stronger validation
- tests and build still pass
